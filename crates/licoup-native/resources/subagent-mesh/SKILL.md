# LicoUp Subagents

List and probe targets before delegation. Delegate, continue, or cancel only an
exact `conversationId + membershipId` in the current Conversation. Native
sessions, paths, endpoints, credentials, prompts, and Agent output remain
private to LicoUp. Never attempt a self-call or a cross-Conversation call.
