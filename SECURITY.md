# Security

Report private client vulnerabilities through the organization's private
security channel. Do not disclose client runtime data, local file paths, logs,
tokens, credentials, backend production data, or user data in public issues or
pull requests.

For examples and fixtures, use placeholders such as `<server-url>`,
`<repo-root>`, `<user-home>`, `<input-file>`, and `<output-file>`.
