Declared support is projected in [Compatibility](COMPATIBILITY.md). A listed capability
is not evidence that it was tested on this machine or released.

Run `npm run verify:closure` for a dated local report covering registered checks,
source projections and explicitly unverified live targets. Reports stay in ignored
build output; public documents do not maintain a parallel acceptance ledger.

Published release assets and their verification receipts establish release status.
Plans, source implementation, static passes and local dates do not establish live
Agent qualification, model ranking, gateway availability or physical pairing success.
