# 规范 Conversation

Updated: 2026-09-26

[English](CONVERSATION-DOMAIN.md) · [模块指南](../modules/conversation.md)

规范 Conversation 拥有身份、成员、事件、回合及连续性历史。原生 Agent Session
是私有执行绑定，不是公开会话身份。原生宿主提供平台副作用和运行端口，独立会话
crate 持有记录及事务不变量。

每项生命周期决策只有一个提交属主。适配器报告协议事实，调度和 Flutter 消费
投影，不以安静的输出、观察者断开或观察窗口结束推断完成。并发按准入的运行时和
Membership 约束，不以 UI 的全局忙碌标志控制。

关联更新原子提交后再通知观察者；分页与过滤归存储属主。撤权来源、私有保留输入
不得进入公开事件或别的会话。产品归档/重置与原生接续分离，不修改第三方 Agent
历史；对端输入保留来源、出处及会话/成员范围。

[转移配置](../../crates/licoup-conversation/resources/state-machines.json)在构建时读取
为不可变查表数据，由本模块执行器执行，配置变更须重新构建。非法转移不改变状态，
终态吸收后续事件；存储比较交换负责提交权，不另定义状态表。测试入口见模块指南。
流式展示和结算见[投影边界](CONVERSATION-VERTICAL-CONTRACT.md)，持久 Assistant
工作见[连续性](CONTINUOUS-ASSISTANT.zh-CN.md)。

## 本地对话

正常对话界面选择本地 Agent，并在提交首条输入时创建持久会话。流式回复必须在轮次终结前可见。
继续发送使用已记录的原生会话绑定和规范成员身份。显式停止作用于当前轮次；之后的输入可在
同一会话中开始新轮次。重新打开客户端保留历史和会话身份。合成检查覆盖生产组合与持久化边界，
真实适配器验收作为独立阶段执行。

## 本地执行过程查看

`agent.conversation.execution` 只观察精确的会话、成员和派发句柄，保留出处和顺序，
不补造历史缺失内容。关闭观察不控制或结算执行。此本机路径可能包含私有运行数据，
不是 MCP 能力或公开导出；普通转录与对外传输边界保持独立，UI 只消费不可变投影。
