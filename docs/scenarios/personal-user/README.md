# Personal User Scenarios

This folder contains scenarios for individual desktop and mobile client users.

- `client-priority-scenarios.md` records the ordered client scenarios: `remote-message`, `file-sync`, `skill-installer`, `skill-sync`, `remote-approval`, `client-update`, and `agent-usage-metering`.
- `skill-installer.md` owns the direct GitHub URL to local target-agent skill installation scenario.
- `shared-client-substrate.md` records the common client trust, addressing, delivery, local effect, and verification substrate used by all personal-user scenarios.
