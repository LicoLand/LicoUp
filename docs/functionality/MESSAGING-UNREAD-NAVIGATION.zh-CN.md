本文档是消息会话列表中未读会话的交互契约。它定义了当联系人存在未读消息时
点击该行的行为、会话的访问顺序，以及会话何时计为已读。

## 术语

- **联系人**：消息列表中代表一个智能体产品的行（合并的 target 共用一行）。
  规范群聊行是会话而非联系人，保留单会话行为。
- **未读**：会话或群聊的持久化已读游标低于其当前消息数。游标在本地持久化；
  持久化存储加载完成后，从未打开过的会话按全量计为未读——除非覆盖基线将其
  收编（见下）。
- **覆盖基线**：持久化游标文档开始记账会话的时刻（文档中的
  `baselineAtUnixMs`；对早于逐会话覆盖的文档，取文件自身的修改时间）。最后
  活动时间早于基线的会话属于既有历史：首次出现时按当前计数收编为已读并持久化；
  基线之后有活动的会话是真正的新会话，按全量计为未读。
- **未读会话**：未读数大于零的联系人会话。子代理线程不单独计数，归属其父会话。

## 行徽章

联系人行的徽章显示该联系人**所有会话的未读消息总数**，而不只是最新会话的
未读数。只有当该联系人的全部会话均已读时徽章才消失。群聊行显示其单会话的
未读数。

## 点击契约

点击联系人行时，将其会话按最新在前排序，打开**第一个仍有未读消息的会话**。
打开即标记该会话已读：游标推进到当前计数，其对徽章的贡献清零。

由于刚打开的会话已被标记已读，再次点击同一行会找到**下一个最新的仍有未读
的会话**并打开它。之后每次点击重复此规则：该行始终进入最新剩余的未读会话。
不维护显式的轮换索引——排序在每次点击时重新计算，因此重新出现未读的会话
（新消息到达）会被同一规则再次拾取。

当该联系人没有任何未读会话时，点击回退到默认行为：打开该联系人最近的会话
（无会话时打开新会话草稿）。这是轮换的终态——「直到所有消息读完」即回退路径
运行的时刻。

折叠为头像栏的呈现方式遵循同一契约。

## 已读语义

- 打开会话——无论通过行点击、会话意图还是视图恢复——立即标记已读；游标不等
  待消息滚入视野。
- 会话打开期间保持已读：消息数增长时游标跟随。选中的会话永远不显示徽章。
- 「仍打开」的标记跟随**实际选中的会话**，而非联系人最新的会话。面板中打开
  的较旧会话不会清除从未打开过的较新会话的未读状态。
- 切走不会把先前打开的会话标回未读；游标只前进。
- 收编基线前会话时会一次性写入其当前计数，此后到达的消息按正常增量计未读。
  保存游标文档不会扩大基线：写入的时刻属于被替换的文档，而非本次保存。

## 边界

- 未读记账覆盖已加载目录页中的会话。目录页之外的会话不参与徽章与轮换，
  直到目录将其加载。
- 群聊行保留既有单会话语义：点击打开群聊并标记已读，无轮换。
- 已读游标是本地持久化状态，不跨设备同步，也不是对智能体可见的已读回执。
