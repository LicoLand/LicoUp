# LicoUp Logo 设计失败复盘 —— 反例档案

> **定性声明：本文档记录的是一个失败的、不可用的设计过程，作为反例存档。**
> 所有产出文件均不可作为品牌资产使用。记录的目的是让下一次设计（无论是人还是 AI）不再重复这些错误。
>
> 记录时间：2026-08-09 ｜ 记录者：Kimi（执行本次设计的 AI 本身）

## 1. 原始设计简报（用户的真实需求）

用户在多轮对话中给出的有效约束，汇总如下：

- **品牌**：LicoUp，发音近 "Link Up"，AI 时代基建级通讯软件，注重隐私与安全，新锐科技品牌。
- **核心概念**：**左右两股力量汇聚到中间扣住**——像安全带卡扣"咔哒"一声扣紧的感觉，但**不要真的安全带**。
- **形式要求**：
  - 简洁有寓意（用户欣赏"蓝色雨伞"Logo 的双关手法：保护 + 雨水元素融合）；
  - 曲线要数学级流畅（参考 Meta 的数学曲线过渡）；
  - 新锐感（参考 ROG 玩家国度）；
  - 必须**具像化**：一眼能读出"无限 / DNA / 互联 / 锁扣 / 锁链 / 安全"中的具体符号，拒绝抽象散乱；
  - 不能直接复刻用户给的聚合类参考图。
- **工艺要求**：先出 PNG 位图稿，不要 SVG 直出；之后可再考虑矢量化。
- **风格参考**（用户多次指认）：
  - `brand/refs/7d5e…jpg`：互扣双环形态；
  - `brand/refs/813be…jpg`：纯黑圆点 + 细线 + 柔影的网络节点风格（白底）；
  - ROG、雨伞、Meta、infinity、DNA 等共 10 张。

## 2. 全过程时间线与每轮方法

### 第 1 轮：手写 SVG 直出（全部作废）
- **方法**：直接手写三个 SVG 概念——相扣双环、双 L 结、汇聚上扬。产出在 `brand/concepts/`、`brand/exports/`。
- **用户反馈**：全部作废。"你应该先用 PNG 出图，之后再考虑转 SVG"，并明确"避免这种 SVG 直出的图片"。
- **失败点**：SVG 手写路径 = 用代码坐标硬凑曲线，没有设计推敲；且违背用户指定的工艺顺序。

### 第 2 轮：AI 图像生成插件（全部作废）
- **方法**：调用本地 image_generation 插件（`scripts/image_generation_tool.py generate`），以 DNA / 无限 / 节点融合为 prompt 生成 D1–D8，产出在 `brand/gen2/`。
- **用户反馈**："均不可用，且完全不符合要求，不好看，特别丑陋"。
- **失败点**：把设计判断外包给生成模型的随机性；prompt 里堆叠意象（DNA+无限+网络），产出意象混杂；无任何形态控制。

### 第 3 轮：程序化节点网络（PIL 绘制）
- **方法**：自建渲染管线——PIL 2 倍超采样画布（2048×1365）、高斯柔影、墨点 `(22,22,26)` + 细连线。依次产出：
  - V2 无限星座：太散，内部淘汰；
  - V3 plexus 有机网络团（`brand/gen3/licoup-v3-plexus.png`）；
  - V4 折线化环：太弱，内部淘汰；
  - V5 相扣双环多边形版（`licoup-v5-clasp-web.png`）。
- **用户反馈**：V3 "似乎稍微有一点点感觉"，但"和无限、DNA、互联、锁扣、锁链、安全没有任何关系，意象特别凌乱，**需要具像化一点**"。
- **失败点**：纹理先于形态。V3 的"一点感觉"只是材质讨喜，符号层面是空白。

### 第 4 轮：具像符号 × 节点星丛（`brand/tools/gen_figurative.py`）
- **方法**：把具像符号当"轮廓约束"，节点+连线当"填充纹理"：
  - V6 锁链：两个跑道形链环 ±16° 倾斜互穿，交叉区做"过/穿"编织，扣点染蓝（`#1B49E0`）；
  - V7 无限：lemniscate 采样 40 节点，中心交叉处断下穿；
  - V8 DNA：双正弦链 + 横档。
- **技术事故**：交叉区检测最初用"点距离聚类"，把上下两个交叉点合并成一个，导致锁扣点丢失；后改为二维欧氏距离聚类，再改为**线段求交**才稳定。
- **结果**：V6 两环根本没有扣上（左右分离、交叉区落在空白、蓝点飘移）；V7 交叉被吃掉；V8 读成"两个笼子"。全部内部淘汰或不可展示。
- **失败点**：用几何约束让寓意"涌现"——寓意只存在于构造逻辑里，眼睛看不见。

### 第 5 轮：V9 网络锁扣（`brand/tools/gen_v9.py`，本轮被否决）
- **方法**：放弃"节点沿轮廓排列"，改为**符号当剪影、网络当肌理**：
  - 两个跑道形链环（L=235, r=250, 环带半宽 58，倾角 ±14°，中心距 500）；
  - 环带内泊松盘采样（目标 64 节点/环，最小间距 47px）；
  - 距离 < 128px 连细线，透明度随距离衰减；
  - 交叉区用**线段求交**精确定位，做上压下让（让行环在交叉区删节点、断连线）；
  - 扣点节点放大 r=32，accent 版染蓝。
- **种子事故**：seed 7（v9）、seed 21（v9b）可展示；seed 33（v9c）出现孤立蓝点 + 右环断裂，被淘汰——**同一套代码换个种子就崩**。
- **用户反馈（终审）**：**"你生成的 Logo 完全不可用。"**

## 3. 失败根因分析（按严重程度排序）

### 3.1 用程序纹理替代了设计本身（根本原因）
Logo 的核心是**形态（form）**——一个有意图的、可被记住的几何手势。我五轮做的全是**纹理（texture）**：节点大小、连线透明度、柔影参数、采样密度。形态从来没有被"画"过，只是被"采样"出来。用户要的"咔哒"是一个动作感，需要的是经过推敲的贝塞尔曲线，不是泊松盘采样。

### 3.2 把"风格参考"误读为"创作媒介"
用户指认 813be 网络节点图是**风格参考**（黑点、细线、柔影的质感取向），我却把"节点网络"这个媒介本身当成了答案。节点星丛是插画/生成艺术的媒介：**不可复现、不可缩放、不可注册、16px 下是一团灰**——它天然不可能成为"长期品牌形象"。

### 3.3 随机性 = 不可复现，而品牌资产必须确定
V9 三个种子三个样子，seed 33 直接崩坏。我把"换个种子再跑一批"当成设计迭代，把"从噪声里挑能看的"当成设计筛选。品牌母版必须是唯一的、确定的、可被精确重建的。

### 3.4 具像化的路径错误：寓意藏在构造里，不在画面上
"过/穿编织""让行断点"这些锁扣语义存在于代码的 if 判断里，画面上一眼看不出。用户要的是**图形本身的具像**——无需解说就能读出"扣住了"。我的每张图都依赖我的文字解说才成立，这恰恰是 Logo 的反义。

### 3.5 迭代被单轮反馈绑架，没有稳定的设计纲领
每轮都朝上一轮最新反馈过度修正：SVG→PNG→AI 生成→plexus→具像，像打地鼠。从未把第 1 节的完整简报作为不变纲领锚定，导致每一轮都在解决上一轮的投诉、制造新问题。

### 3.6 跳过草图发散阶段，每一稿都是"成品渲染"
正确的 Logo 流程：几十个小拇指级草图发散**形态** → 筛选 → 精修。我每一轮都直接产出 2048px、带柔影的"成品"，单稿成本高，于是对产出产生防御心理（"再修修参数就好了"），无法做到真正的发散与舍弃。

### 3.7 质检标准错位
我的自检是"没有孤立节点、交叉干净、阴影正常"——这是工程洁净度检查。从未做过 Logo 的真实质检：**缩到 16/32/64px 是否可辨？单色反白是否成立？剪影是否独特？0.5 秒内能否认出？** 这些测试一次都没做。

### 3.8 对参考仓库经验的执行走样
用户曾指向 KimiSpace 仓库的 Logo 生成管线（因 OneDrive 水合失败未能读取，仅凭文件名推断：宽探索 → 程序化清洗 → 矢量化 → 逐阶段质检 → 打包）。我口头上承认该管线，实际执行中**跳过了"宽探索"和"逐阶段质检"两个关键环节**，只做了中间的生产环节。

## 5. 如果重做，正确的流程应该是

1. **锚定简报**：以第 1 节为唯一纲领，任何一轮产出逐条对照验收。
2. **形态发散（纯草图）**：只用粗线/剪影画 20+ 个拇指草图，全部围绕"左右汇聚、中间扣住"这一个动作；不画任何纹理。此阶段可以用纸、矢量软件或代码——但产出必须是**形态**，不是材质。
3. **形态筛选**：把草图缩到 64px 做盲测，只留 3 个剪影可读、寓意直白的方向。
4. **矢量精修**：入选方向用贝塞尔曲线精绘（Meta 式数学曲线在此阶段才进入），确定唯一母版。
5. **应用测试**：单色、反白、16px favicon、字标搭配、深/浅底，全部通过才算成立。
6. **风格层最后加**：如果届时仍想要节点网络质感，它是**第 6 步的装饰层**，不是第 1 步的起点。
7. **全程确定性**：母版从草图到成品必须可精确复现，禁止任何随机种子依赖。
